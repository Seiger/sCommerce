# Справочник цен

`sPriceResolver` возвращает единые поля цен. События `evolution.sCommerceResolveProductPriceMode` и `evolution.sCommerceResolveProductPrice` сохраняют поддержку.

Приоритет: персональная или накопительная цена sPricing, акционная, базовая. Старая цена — основа предоставленной скидки.
