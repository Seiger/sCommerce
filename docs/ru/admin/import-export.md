# CSV-импорт и экспорт

Откройте **Интеграции → CSV-импорт/экспорт**. Экспортируйте свежий файл как шаблон. Разделитель колонок — точка с запятой; элементов списка категорий — `||`.

## Поля категорий

| Поле | Один сайт | Мультидомен |
| --- | --- | --- |
| `category` — основная категория | `2` | `default:2\|\|shop:234` |
| `categories` — дополнительные категории | `240\|\|238` | `240\|\|238` |

`category` содержит один ID основной категории для одного сайта. В мультидоменном режиме — пары `domain:id`: используйте ключи доменов из настроек sMultisite и ID существующих ресурсов категорий.

`categories` содержит дополнительные ID. Основные категории всех доменов исключены из этого списка. Редактор товара также исключает основные категории из дополнительных и обновляет выбор при смене основной категории.

## Старые файлы

Отдельная колонка `parent` удалена. Перед импортом старого файла перенесите прежний список категорий в `categories`, а основной ID — в `category`. Сохранена поддержка доменных полей `category_<domain>` и старых `parent_<domain>`.

Потоковый импорт и импорт через временную таблицу сохраняют доменные scope и существующие позиции товаров в категориях.
