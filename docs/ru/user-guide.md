# Цены витрины

Без sPricing sCommerce показывает прежнюю базовую или акционную цену. С sPricing покупатель может получить персональную или накопительную цену. Одно правило действует в каталоге, карточке товара, корзине и checkout.

Гость получает активную акционную цену, а персональная цена доступна только назначенному пользователю.
