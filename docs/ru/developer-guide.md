# Динамические цены

`sPriceResolver` — единая точка получения `price`, `oldPrice`, `priceAsFloat` и `oldPriceAsFloat` в модели товара, витрине, корзине и checkout.

Если sPricing доступен, он получает контекст текущего пользователя. Иначе сохраняется историческое правило `price_special` / `price_regular`.

Кэшированные данные товара и страницы остаются нейтральными. Resolver применяет цену текущего пользователя в рамках запроса, поэтому общий кэш не передаёт цену одного клиента другому.
