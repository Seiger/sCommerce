# Ціни у вітрині

Без sPricing sCommerce показує стандартну базову або акційну ціну товару. З установленим sPricing ціна покупця може залежати від його персонального виду ціни або накопичувальної знижки.

Однакове правило діє у каталозі, картці товару, кошику та checkout. Для гостя застосовується акційна ціна, якщо вона активна; персональна ціна доступна тільки призначеному користувачу.

# Повторення замовлення

У меню рядка замовлення `•••` виберіть **Повторити замовлення**. Відкриється
редагована копія з клієнтом, товарами та цінами оригіналу. Перевірте контактні
дані й склад замовлення: можна змінити кількість, додати або прибрати товари.
Ціни оригіналу не переоцінюються автоматично за поточним каталогом.

Нове замовлення з новим номером створюється лише після **Зберегти**.
Закриття форми без збереження нічого не створює. Повторне надсилання тієї самої
форми повертає вже створене замовлення.

Копія отримує статус «Нове» та початковий статус оплати. Старі платежі,
платіжні посилання, ТТН, історія, менеджерські нотатки та вартість доставки
не переносяться. Метод доставки й основні адресні поля зберігаються, але їх
слід перевірити перед відправленням. У новій історії фіксуються вихідне
замовлення та менеджер, який створив копію. Оригінал залишається незмінним.
