# CSV-імпорт та експорт

Відкрийте **Інтеграції → CSV-імпорт/експорт**. Експортуйте свіжий файл як шаблон. Роздільник колонок — крапка з комою; елементів списку категорій — `||`.

## Поля категорій

| Поле | Один сайт | Мультидомен |
| --- | --- | --- |
| `category` — основна категорія | `2` | `default:2\|\|shop:234` |
| `categories` — додаткові категорії | `240\|\|238` | `240\|\|238` |

`category` містить один ID основної категорії для одного сайту. У мультидоменному режимі — пари `domain:id`: використовуйте ключі доменів із налаштувань sMultisite та ID наявних ресурсів категорій.

`categories` містить додаткові ID. Основні категорії всіх доменів виключені з цього списку. Редактор товару також виключає основні категорії з додаткових та оновлює вибір під час зміни основної категорії.

## Старі файли

Окрему колонку `parent` прибрано. Перед імпортом старого файлу перенесіть колишній список категорій у `categories`, а основний ID — у `category`. Збережено підтримку доменних полів `category_<domain>` та старих `parent_<domain>`.

Звичайний імпорт і імпорт через тимчасову таблицю зберігають доменні scope та наявні позиції товарів у категоріях.
