# Керування магазином

sCommerce надає каталог товарів, кошик, оформлення й керування замовленнями для Evolution CMS. Інтерфейс і набір вкладок залежать від налаштувань магазину та встановлених інтеграцій.

## Актуальні можливості

- Кошик, оформлення замовлення, замовлення в один клік та список бажань.
- Прості та згруповані товари; атрибути, діапазони цін, галереї, відгуки й рейтинг.
- Основна й додаткові категорії, позиції товару в категоріях, фільтрація та сортування.
- Замовлення, статуси, масові дії, експорт і повторення замовлень, облік платежів.
- Готівка та банківський рахунок; кур’єрська доставка й самовивіз. Інші провайдери розширюють пакет.
- CSV-імпорт/експорт товарів із перекладами, SEO-полями, галереями, атрибутами й мультидоменними категоріями.
- XML-фіди Google Merchant; фонові завдання та кеш каталогу через sTask.
- Статистика dashboard та історичні метрики товарів і відгуків.
- Кілька валют і ручні дробові курси; необов’язкова інтеграція sPricing для контекстних цін.

## Основна й додаткові категорії

Категорія — основна категорія товару. Додаткові категорії містять лише інші прив’язки: основну не можна вибрати там повторно. Зміна основної категорії одразу оновлює поле. У мультидоменному режимі кожен домен має свою основну категорію.

У мовній вкладці контенту заповніть назву товару; задайте SKU, псевдонім, доступність, ціну й валюту. Виберіть основну та за потреби додаткові категорії, додайте фото через sGallery. Опублікуйте товар і перевірте його сторінку.

## Курси валют

Доступні та основну валюту задають у налаштуваннях. Вкладка Валюти з’являється, коли ввімкнено понад одну валюту. A → B — окремий множник конвертації: дозволені 50.55 і 0.012345. Зворотну пару задайте явно; автоматичного завантаження курсів немає. Значення зберігаються в core/custom/config/seiger/settings/sCommerceCurrencies.php. Для відсутньої пари типовий курс — 1; явно заданий нуль не слід трактувати як гарантоване 1:1. Кількість знаків у відображенні ціни налаштовується окремо від точності курсу.

## CSV-імпорт та експорт

Використовуйте Інтеграції → CSV-імпорт/експорт. Експортуйте свіжий файл як шаблон: роздільник колонок — крапка з комою, елементів списку категорій — ||. Колонка Категорія (category) для одного сайту містить ID основної категорії. Додаткові категорії (categories) містять решту ID без основних категорій доменів. Для мультидомену category має формат domain:id, наприклад default:2||shop:234; categories залишається списком додаткових ID. Збережено підтримку імпорту `parent_<domain>`; окрему колонку parent прибрано. Звичайний імпорт і шлях через тимчасову таблицю зберігають доменні scope та позиції. У старих файлах перенесіть колишній список категорій у categories, а основний ID — у category.
