# Довідник цін

`sPriceResolver` повертає узгоджені поля відображення ціни для всіх поверхонь sCommerce. Старі події `evolution.sCommerceResolveProductPriceMode` і `evolution.sCommerceResolveProductPrice` залишаються підтримуваними для проєктних перевизначень.

Пріоритет: застосовна персональна або накопичувальна ціна sPricing, далі акційна ціна, далі базова ціна. Старою ціною показується ціна, від якої фактично надано знижку.
