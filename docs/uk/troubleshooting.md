# Усунення проблем

- У користувача показується ціна гостя: перевірте його авторизацію та призначений персональний вид ціни.
- Каталог показує застарілу ціну після зміни: очистіть кеш Evolution; дані товару й контекстна ціна кешуються окремо.
- Після вимкнення sPricing: sCommerce автоматично повертається до стандартних полів базової та акційної ціни.
