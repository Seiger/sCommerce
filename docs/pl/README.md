# sCommerce dla Evolution CMS

sCommerce udostępnia katalog produktów, koszyk, składanie i obsługę zamówień w Evolution CMS. Interfejs i zakładki zależą od konfiguracji oraz zainstalowanych integracji.

## Aktualne możliwości

- Koszyk, finalizacja zakupu, zamówienia jednym kliknięciem i lista życzeń.
- Produkty proste i grupowane; atrybuty, zakresy cen, galerie, opinie i oceny.
- Kategorie główne i dodatkowe, pozycje produktów, filtrowanie i sortowanie.
- Zamówienia, statusy, działania zbiorcze, eksport, ponawianie i ewidencja płatności.
- Gotówka i faktura bankowa; kurier i odbiór osobisty. Pozostali dostawcy są rozszerzeniami.
- Import/eksport CSV z tłumaczeniami, polami SEO, galeriami, atrybutami i kategoriami wielu domen.
- Kanały XML Google Merchant; zadania w tle i pamięć podręczna przez sTask.
- Statystyki panelu i historyczne metryki produktów oraz opinii.
- Wiele walut, ręczne kursy ułamkowe i opcjonalne ceny kontekstowe przez sPricing.

- sPricing

Integrację sApi i osobny pakiet sCommerce API opisuje przewodnik API. Logowanie, profil klienta oraz zewnętrzne płatności i dostawy zapewnia projekt lub rozszerzenia.

## Wymagania

- PHP **8.4+**
- Evolution CMS **3.5.8+**
- Composer
- sGallery, sTask (Composer dependencies)
