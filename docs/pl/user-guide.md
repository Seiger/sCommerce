# Ceny w sklepie

Bez sPricing sCommerce pokazuje dotychczasową cenę bazową lub promocyjną. Z sPricing kupujący może otrzymać cenę osobistą albo narastającą. Ta sama zasada działa w katalogu, na stronie produktu, w koszyku i checkout.

Gość otrzymuje aktywną cenę promocyjną, a cena osobista jest dostępna wyłącznie dla przypisanego użytkownika.
