# sCommerce

sCommerce ist das unabhängige Evolution-CMS-Paket für Katalog, Warenkorb und Checkout. Wenn sPricing vorhanden ist, können Kontextpreise ohne Änderung der bestehenden Produkt-API angewendet werden.
