# Shoppreise

Ohne sPricing zeigt sCommerce den bisherigen Basis- oder Aktionspreis. Mit sPricing kann ein Käufer einen persönlichen oder kumulativen Preis erhalten. Die gleiche Regel gilt in Katalog, Produktseite, Warenkorb und Checkout.

Gäste erhalten einen aktiven Aktionspreis; ein persönlicher Preis ist nur für den zugewiesenen Benutzer verfügbar.
