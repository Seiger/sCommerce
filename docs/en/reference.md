# Pricing reference

`sPriceResolver` provides consistent display fields for all sCommerce surfaces. Existing events `evolution.sCommerceResolveProductPriceMode` and `evolution.sCommerceResolveProductPrice` remain supported for project overrides.

Priority: applicable sPricing personal or cumulative price, then promotional price, then base price. The old price is the price from which the effective discount was granted.
